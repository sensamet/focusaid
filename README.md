# Focusaid 🌿

Focusaid is a premium, high-performance focus timer application designed to turn your productivity into real-world impact. By combining deep focus sessions with charitable giving, Focusaid motivates you to stay on task while contributing to meaningful causes like reforestation and animal welfare.

## ✨ Features

- **🎯 Deep Focus Timer**: A beautiful, customizable Pomodoro-style timer with smooth animations and a "Glassmorphism" design.
- **🤝 Real-World Impact**: Every completed session contributes to real impact (e.g., donating pet food, planting trees) through simulated charitable cycles.
- **📊 Productivity Dashboard**: Track your focus sessions, daily streaks, and the total impact you've made over time.
- **🚀 Demo Mode**: Instantly experience the reward flow with the "Demo" button to see how your focus translates into aid.
- **💎 Premium UI/UX**: Built with a sleek dark theme, vibrant emerald gradients, and interactive micro-animations.
- **📱 Responsive Design**: Fully optimized for all devices, from desktop to mobile.

## 🛠️ Technology Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started

To run Focusaid locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sensamet/Focusaid.git
   cd Focusaid
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```
